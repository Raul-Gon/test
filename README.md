# 👟 Zalando Clone - Módulo de Zapatería Dinámico con Astro

[![Desplegado en Netlify](https://shields.io)](https://zalandotest.netlify.app/)
[![GitHub Repo](https://shields.io)](https://github.com/Raul-Gon/test)

Este proyecto nace como un desafío técnico dentro de mi formación especializada para replicar un entorno de producción real de E-commerce. El objetivo principal ha sido maquetar fielmente la **página principal de Zalando** y desarrollar por completo la lógica funcional del **módulo de zapatería**, implementando un sistema de filtrado dinámico reactivo y eficiente.

🚀 **Puedes ver el proyecto en vivo aquí:** [Zalando Clone en Netlify](https://zalandotest.netlify.app/)

---

## 🎯 Objetivos Técnicos y de Negocio Conseguidos

*   **Réplica Pixel-Perfect:** Reutilización de componentes visuales, tipografías y estructuras UX/UI de una de las plataformas de moda líderes en Europa.
*   **Interactividad Avanzada:** Implementación de lógica de filtrado dinámico de artículos (por categorías, marcas, precios y estilos) enfocado en mejorar la conversión del usuario.
*   **Rendimiento Óptimo:** Aprovechamiento de la arquitectura orientada a componentes que ofrece Astro para lograr tiempos de carga mínimos.

---

## 🛠️ Stack Tecnológico Utilizado

*   **Framework Principal:** [Astro](https://astro.build) (Aprovechando su alto rendimiento y carga ultra rápida de componentes estáticos e interactivos).
*   **Maquetación y Estilos:** HTML5 semántico y CSS3 estructurado (Mobile-First para asegurar un diseño 100% responsivo en smartphones, tablets y ordenadores).
*   **Lógica de Filtros:** JavaScript ES6+ modular para el procesamiento dinámico del catálogo de productos de zapatería en tiempo real.
*   **Despliegue Continuo (CI/CD):** Git/GitHub integrado con Netlify para compilaciones automáticas basadas en ramas de producción.

---

## 💡 Destacados Técnicos (Lo que aporta valor a tu equipo)

### 1. Sistema de Filtrado de Catálogo Reactivo
Desarrollé la lógica que maneja el catálogo de calzado (sandalias, zapatillas, mocasines, botas). Los filtros permiten actualizar la interfaz de manera fluida sin recargas completas de página, imitando el comportamiento de las grandes aplicaciones web de venta online.

### 2. Estructura de Proyecto Limpia y Escalable
El proyecto sigue las mejores prácticas de organización de archivos recomendadas para la arquitectura moderna en componentes:

```text
├── public/              # Activos estáticos, imágenes de marcas y productos
├── src/
│   ├── components/      # Componentes reutilizables de la interfaz (Navbar, Footer, Cards)
│   ├── layouts/         # Plantillas de diseño base de la aplicación
│   └── pages/           # Enrutamiento basado en archivos (Landing, Zapatería)
├── astro.config.mjs     # Configuración del motor de construcción
└── netlify.toml         # Configuración avanzada de cabeceras y entorno de despliegue
```

### 3. Foco en la Optimización (Core Web Vitals)
Al haber elegido **Astro**, el sitio minimiza el peso del JavaScript del lado del cliente, garantizando una excelente puntuación de velocidad en buscadores y una tasa de rebote baja para los usuarios finales.

## 🚀 Instalación y Desarrollo Local

Si deseas auditar el código o ejecutar este proyecto localmente para evaluar su calidad, sigue estos pasos:

1. Clona este repositorio en tu máquina:
   ```bash
   git clone https://github.com
   ```
2. Entra en la carpeta del proyecto:
   ```bash
   cd test
   ```
3. Instala todas las dependencias necesarias:
   ```bash
   npm install
   ```
4. Inicia el servidor de desarrollo local:
   ```bash
   npm run dev
   ```
5. Abre en tu navegador la dirección: `http://localhost:4321`
